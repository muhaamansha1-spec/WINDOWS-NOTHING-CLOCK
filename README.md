# Nothing Clock for Windows

A sleek, lightweight **Nothing OS-inspired Clock application** for Windows, built with modern web technologies and packaged as a native desktop app.

Designed to capture the clean aesthetic of Nothing OS while providing essential clock utilities with smooth animations and a distraction-free interface.

## ✨ Features

- 🕒 Digital clock with Nothing-inspired design
- ⏰ Alarm management
- ⏱️ Stopwatch
- 🍅 Focus Timer (Pomodoro)
- 🌍 World Clock
- 🌙 Dark theme with Nothing-style dot matrix typography
- 📌 Always-on-top mode
- 🖥️ Dock Mode for desktop use
- ⚡ Lightweight and fast
- 💻 Native Windows application

## 🚀 Getting Started

### Prerequisites

- Node.js 20+
- npm

### Installation

Use latest installer.exe from releases. It it recommended to install nothing font (5x7) and opt it in the setting for bestexperience
